## 快速观察

- **Senior 占绝对多数**：7 个 JD 全要求 3-4 年以上经验，junior 岗基本不见——北欧数据团队的 HC 很稀缺，倾向招一个能独立交付的人
- **现代数据栈是主线**：dbt、Snowflake、BigQuery、Databricks、Airflow 出现率最高，传统 ETL 工具只有 Azure Data Factory 还在
- **云三分天下**：AWS（2）、Azure（2）、GCP（1），没有一家是"多云混合"描述，通常明确绑定一个云
- **Hybrid 是默认**：只要写了工作模式的，都是混合办公；远程全职岗位未见
- **文化信号写进 JD**：不要 cover letter（H&M）、披露完整面试流程（Flower）、说明不提供 relocation（Flightradar24）——北欧式直白
